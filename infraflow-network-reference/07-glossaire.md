# 07 — Glossaire réseau

| Terme | Définition |
|---|---|
| ACL | Access Control List : règles de filtrage de paquets |
| ARP | Résolution IPv4 vers MAC sur un segment local |
| AS | Autonomous System, ensemble de réseaux sous politique de routage commune |
| BGP | Protocole de routage inter-domaines |
| CIDR | Notation de préfixe réseau |
| DHCP | Attribution dynamique de paramètres IP |
| DNAT | Traduction de l'adresse de destination |
| DNS | Résolution de noms |
| DSCP | Champ de marquage QoS IP |
| HA | Haute disponibilité |
| HSRP | Protocole Cisco de redondance de passerelle |
| IGP | Interior Gateway Protocol |
| LACP | Agrégation dynamique de liens |
| MTU | Taille maximale d'un paquet/trame selon la couche considérée |
| NAT | Network Address Translation |
| NDP | Neighbor Discovery Protocol IPv6 |
| NTP | Synchronisation de l'heure |
| OSPF | Protocole IGP à état de liens |
| PAT | Traduction avec multiplexage par ports |
| QoS | Qualité de service |
| SVI | Interface VLAN commutée |
| SNAT | Traduction de l'adresse source |
| STP | Spanning Tree Protocol |
| Syslog | Format/protocole de journalisation |
| VLAN | Réseau local virtuel de couche 2 |
| VRF | Virtual Routing and Forwarding |
| VRRP | Protocole de redondance de passerelle |
| ZTP | Zero-Touch Provisioning |
